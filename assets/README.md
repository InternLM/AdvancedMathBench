# Paper figures

These figures are converted directly from the author-supplied original PDF
artwork used in the final AdvancedMathBench manuscript dated September 28, 2026.

| Asset | Paper location | Original artwork |
|---|---|---|
| [teaser_benchmark_difficulty.svg](teaser_benchmark_difficulty.svg) | Figure 1, left | `teaser_benchmark_difficulty.pdf` |
| [verification_tpr_tnr_metaver.svg](verification_tpr_tnr_metaver.svg) | Figure 1, right | `verification_tpr_tnr_metaver.pdf` |
| [overview.svg](overview.svg) | Figure 2 | `advancedmathbench_overview_editable_vector_appended.pdf` |

The SVG exports preserve vector shapes, convert text to paths to avoid font
substitution, and retain the PDF's white page background for readability in
both light and dark themes. Embedded bitmap elements in the source artwork
remain embedded bitmaps; plots and labels have not been redrawn or regenerated.

Figure 2 describes the paper's overall pipeline, not additional training
functionality provided by this evaluation repository. The earlier `overview.png`
is retained as a fallback; the README uses the SVG originals above.
